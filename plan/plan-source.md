Higdon's own governing principles, which the compressed plan must respect:

- Long run is the key session. Every 3rd week is a stepback. Do not cheat on
  long runs.
- Long runs 30–90+ s/mi slower than marathon pace. Physiological benefit
  kicks in at 90–120 min regardless of pace. Covering the distance matters,
  not the speed.
- Saturday pace run sits *before* Sunday long deliberately — to pre-fatigue,
  so the long run isn't run too fast. Preserve this pairing where possible.
- No speedwork in Int 1. Do not add any.
- Friday is a rest day by design. Monday is cross-training.
- 3/1 finish (last quarter faster) allowed on at most one long run in three.

Two 20-milers total (weeks 13, 15). Not three.
